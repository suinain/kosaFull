# 프로젝트 학습 안내

`npm run dev`로 개발 서버를 실행합니다. `npm run lint`로 정적 검사를 수행하고, `npm run build`가 성공한 뒤 `npm run start`로 프로덕션 서버를 실행합니다. 기본 주소는 http://localhost:3000 입니다.

## 파일과 주석

JavaScript 파일에는 예제 목적을 설명하는 한국어 주석, CSS에는 스타일 적용 범위, SVG에는 자산 역할을 설명하는 주석을 추가했습니다. `node_modules`, `.next`, `.git`은 의존성·자동 생성 결과·저장소 메타데이터이므로 수정하지 않습니다.

JSON과 바이너리는 유효한 형식을 유지하기 위해 내부에 주석을 추가하지 않습니다.

| 파일 | 역할 |
| --- | --- |
| `package.json` | 실행 명령과 React·Next.js 등 의존성 버전 정의 |
| `package-lock.json` | 설치되는 의존성의 정확한 버전 고정. npm이 관리 |
| `jsconfig.json` | `@/`로 프로젝트 루트에서 import할 수 있도록 경로 별칭 설정 |
| `public/images/*.jpg` | 이미지 출력 및 props·state 예제용 사진 |
| `public/logo512.png` | 공통 헤더의 React 로고 |
| `app/favicon.ico` | 브라우저 탭 아이콘 |

## 예제 동작과 수정 사항

- 이벤트: 부모의 `onClick` prop을 자식 버튼에 연결합니다. 이벤트 객체와 추가 인자를 함께 전달하고 `currentTarget`으로 이벤트가 연결된 요소를 읽습니다.
- props: `version={19}`를 전달하면 19, 생략하면 기본값 18을 표시합니다. 태그 내부의 이미지는 `children`입니다.
- state: 원시 state의 숫자는 1씩, 객체 state의 숫자는 기존 예제 의도대로 3씩 증가합니다. 무작위 색상은 항상 유효한 6자리 HEX 문자열로 생성합니다.
- 이미지: 자식 버튼이 부모의 변경 함수를 호출하여 `photo1.jpg`와 `photo2.jpg`를 전환합니다.
- 폼: form 제출로 필수값과 이메일 형식을 검사하며, 새로고침 없이 결과를 표시합니다.
- 라우팅: `URLSearchParams`로 쿼리를 인코딩하고 절대 경로로 이동합니다.
- 로그인: form 제출과 초기화 버튼이 동작하며, 로그인 후 인증 예제로 이동합니다. 로그아웃은 Context와 localStorage를 비운 뒤 `router.push`로 이동합니다.
- 공통 레이아웃: 한국어 문서 언어를 지정하고 Suspense 대기 내용을 실제 JSX로 표시합니다.

로그인은 서버 인증을 구현하지 않은 **학습용 모의 로그인**입니다. 비밀번호를 서버에서 검증하지 않고 고정 토큰으로 Context와 localStorage 사용법을 연습합니다.

런타임 오류 예제는 정상 상태로 열립니다. 해당 파일에 주석 처리된 `{name.length}`를 활성화하면 의도적인 오류와 `app/error.js` 화면을 실습할 수 있습니다.

## 검증 결과 (2026-11-05)

- `npm run lint` 통과.
- `npm run build` 통과, 정적 페이지 생성 완료.
- 빌드된 앱을 Edge 헤드리스 브라우저로 검사: 사용자 페이지 27개가 모두 HTTP 200으로 열림.
- props 기본값, 부모·자식 클릭 이벤트, 숫자 증가, 이미지 왕복 전환, 필수값 검사와 폼 제출, 쿼리 전달, Context 색상 변경 확인.
- 로그인 취소 시 입력 초기화, 빈 폼 제출 차단, 모의 로그인 후 이동, 새로고침 후 상태 복원, 헤더 로그아웃 후 저장소 초기화 확인.
- 없는 경로의 HTTP 404 확인. 정상 페이지와 위 사용자 동작에서 브라우저 JavaScript 오류 없음.
- 소스·스타일·SVG 53개 파일의 주석 존재 및 JSON 파일 형식 유효성 확인.

의도적으로 주석 처리된 런타임 오류 코드를 활성화하는 실습은 자동 검증 범위에서 제외했습니다.
